Проекты курса "Инженер по тестированию" от Яндекс Практикума.
Здесь представлены проекты, которые я выполнила во время прохождения курса "Инженер по тестированию" от Яндекс Практикума 👨‍💻

Проекты:
1) Регрессионное тестирование приложения ”Mesto”
Задачи на проекте:
Анализ документации;
Поиск серых зон;
Уточнение требований;
Написание тестовой документации;
Тестирование по написанным тест-кейсам;
Ретест багов.

2) Тестирование приложения Яндекс Маршруты
Задачи на проекте:
Анализ документации;
Поиск серых зон;
Уточнение требований;
Создание mindmap;
Написание чек-листа и тест-кейсов;
Выделение КЭ и ГЗ (таблица в Excel);
Проверка новой фичи на фронтенде с помощью Charles;
Заведение баг-репортов;
Написание отчета;

3) Тестирование мобильного приложения Яндекс Метро на Android
Задачи на проекте:
Анализ документации;
Поиск серых зон;
Уточнение требований;
Написание чек-листа и тест-кейсов;
Регрессионное тестирование;
Тестирование функциональности приложения в Android Studio;
Заведение баг-репортов;
Написание отчета.

4) Тестирование функциональности API Яндекс Прилавка
Задачи на проекте
Анализ документации;
Поиск серых зон;
Уточнение требований;
Выделение КЭ и ГЗ (таблица в Excel);
Написание чек-листа;
Тестирование API в Postman по чек-листу;
Написание отчета.

5) Проект работа с БД Яндекс Прилавка
Задачи на проекте:
Работа в Cygwin;
Написание SQL-запросов.
Навыки:  
- Анализ требований и создание тестовой документации (тест-кейсы, чек-листы)  
- Проведение функционального, регрессионного и позитивного/негативного тестирования  
- Кроссбраузерное и кроссплатформенное тестирование веб-приложений  
- Взаимодействие с командой разработки, составление отчетов о найденных дефектах  
- Базовые знания SQL для проверки данных в базе  
- Основы работы с API и тестирование с помощью Postman  
- Понимание жизненного цикла разработки ПО (SDLC) и процесса тестирования (STLC)  
- Использование баг-трекинговых систем и тест-менеджмента  
- Применение методов и практик Agile/Scrum  

Инструменты:   
- Postman (тестирование API)  
- Базовые SQL-запросы для проверки и валидации данных (MySQL или PostgreSQL)  
- Chrome DevTools и другие браузерные инструменты для тестирования и отладки  
- Браузеры: Chrome, Firefox, Edge для кроссбраузерного тестирования  # nastasia-miha1
